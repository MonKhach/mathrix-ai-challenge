| D1 | 2026-10-22 | Benchmark speech-to-text candidates on this laptop before choosing a model | Pick a model by reputation | Armenian is low-resource and the CPU is limited; only measurements on this machine are reliable |

| D5 | 2026-10-23 | **No paid tools, services or APIs.** If something paid turns out to be essential, stop and decide together | Paid APIs or services | Project rule set by the user |

| D7 | 2026-10-23 | Python 3.11 (3.11.3 already installed) | Newer Python (3.12+) | Already installed; 3.11 has the widest support among ML/audio libraries |
| D8 | 2026-10-23 | Use **PyAudioWPatch** (WASAPI) for both microphone and system-audio loopback capture | SoundCard; VB-Audio Virtual Cable | Built for Windows WASAPI loopback, Python 3.11 wheel, prints device list. **M1 test passed:** mic (idx 12) + headphones loopback (idx 13) recorded simultaneously, 5.00 s / 4.99 s captured, 0 overflows, both recordings clean |
| D9 | 2026-10-23 | Open devices at their native format (48 kHz stereo) and convert to 16 kHz mono in our code | Ask Windows for 16 kHz directly | WASAPI shared mode does not convert formats; all devices on this laptop report 48 kHz / 2 ch. | D10 | 2026-10-23 | Evaluation set v1 = **15 clips: 7 own voice (mic) + 8 YouTube videos/podcasts (system loopback)**, recorded with `scripts/record_clip.py`; references in `eval/references.tsv` | Common Voice / FLEURS clips; friends' recordings | Could not download Common Voice or FLEURS. Own + YouTube clips are closer to real conversation (and avoid models' training-data overlap). Limitation: small sample, no real call-codec audio yet → add friends' call clips at M4 |
| D11 | 2026-10-23 | **Text normalization for scoring** (applied identically to reference and model output, fixed *before* seeing any results): (1) remove punctuation `, . ։ ՝ ՞ ՜ ՛ « » ? ! - ( )`; (2) lowercase; (3) `և` → `եւ`; (4) collapse whitespace. **Not normalized:** colloquial vs literary forms (`ա`/`է`, `էս`/`այս`…), digits vs number words (clips with digits: video_05, video_07, video_08 are flagged in results). References written **as spoken**. Report **raw WER + normalized WER + normalized CER**, plus a per-clip report | No normalization; full normalization to standard spelling incl. numbers | Remove only differences that cannot be heard (punctuation, case, spelling variant of `և`) so real recognition errors are never hidden; safeguards make every mistake visible |
| D12 | 2026-10-23 | Benchmark **NVIDIA FastConformer Armenian via ONNX** (`OpenVoiceOS/stt_hy_fastconformer_hybrid_large_pc_onnx`, runtime `onnx-asr`) as the main candidate, compared against **chillarmo/whisper-large-v3-turbo-armenian** (Transformers) | NVIDIA via NeMo; original Whisper; MMS; SeamlessM4T | NVIDIA: best open model on ArmBench-ASR (19.9 % WER), small (~115M params), ONNX avoids NeMo's "Linux preferred" risk on Windows (trade-off: CTC decoder only, slightly less accurate than Transducer). Whisper-turbo: contrasting architecture, gives a measured comparison. Original Whisper/MMS/Seamless skipped — weaker or too heavy per ArmBench |
| D13 | 2026-10-23 | Project layout `app/` (program), `evaluation/` (metrics + benchmark), `tests/`, `results/`; libraries **scipy** (resampling), **jiwer** (WER/CER), **pytest** (tests) | Own resampler / own WER code / manual checks | Standard, well-tested libraries; our own normalization (D11) is applied before jiwer so the rules stay under our control |
